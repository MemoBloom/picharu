# Google 登录图标

`google-g.png`是Google官方原图，未重绘、调色或使用Gmail信封代替Google账号标识。来源：https://developers.google.com/static/identity/images/g-logo.png ，核对时间2026-10-20。品牌使用规则：https://developers.google.com/identity/branding-guidelines 。此商标素材按Google品牌规则使用，不作为picmoko自有图案授权。

GoogleSignInButton在白底按钮中等比显示20px图标，并保留日文操作文字。图标为装饰性内容，alt为空，读屏通过按钮文字识别。按钮保留键盘焦点、禁用和连接中状态，沿用现有Supabase OAuth处理。
