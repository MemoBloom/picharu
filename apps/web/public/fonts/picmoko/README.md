# picmoko self-hosted fonts

Updated 2026-10-20 after the user confirmed the font combination.

## Active families

- Zen Kaku Gothic New 400/700: body, controls, labels, tool names, h3 and supporting copy. Buttons inherit this family. Existing intermediate CSS weights resolve to these real cuts; synthetic weight/style is disabled.
- Zen Maru Gothic 700: h1/h2 and the prominent upload title.
- The approved A1 wordmark is an independent image asset and has not been recolored or regenerated by this font change.

`src/app/fonts.css` contains 364 active unicode-range faces: 242 Zen Kaku subsets plus 122 Zen Maru heading subsets. `font-display: swap` and local Japanese fallback families keep text visible. Only subsets needed by the current text are requested; the complete fonts are not preloaded. Files are served from the app origin, without a browser request to Google or a build-time font download.

## Sources and manifests

- `zen-kaku-manifest.json`: new Zen Kaku Gothic New 400/700, 242 WOFF2 files, 2,823,460 bytes. Original versioned URL, bytes and SHA256 are recorded per file. See `zen-kaku-gothic-new-OFL.txt`.
- `manifest.json`: earlier Fredoka/Zen Maru bundle, 245 files, 4,104,896 bytes. The Zen Maru 700 subsets remain active; older Zen Maru 400 and Fredoka assets are retained for history and rollback, without active font-face declarations.
- Only content-hashed WOFF2 names have immutable cache headers. Do not replace a hash-named file with different content. License and manifest files are not marked immutable.

Official directories:

- https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew
- https://github.com/google/fonts/tree/main/ofl/zenmarugothic
- https://github.com/google/fonts/tree/main/ofl/fredoka (historical)

All three font distributions use SIL Open Font License 1.1; preserve their notices. No paid font or proprietary system font is redistributed. The small text-only specimen fonts in the workspace design review are separate from these application font assets.
