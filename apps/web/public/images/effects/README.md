# Synthetic imagegen demonstrations

Updated 2026-10-22. These fictional subjects and edits were generated with the built-in image_gen tool for local website demonstrations. The first six pairs were approved by the user; the new batch awaits human aesthetic review. They are not outputs or evaluation evidence from the production provider.

The catalog contains 18 tools and 23 results. Each tool uses a different input; composite uses two, totaling 19 originals. Six avatar styles share the selected cafe woman. There are 42 unique 1000px WebP files (4,837,988 bytes), including the avatar original reused from /images/samples/cafe-woman-v1.webp.

Most folders contain before.webp and after.webp. The cafe folder contains the original soft-anime after.webp plus flat-sticker.webp, soft-3d.webp, chibi.webp, clay-felt.webp and paper-cut.webp. The composite-garden folder contains the second input only. The two new material variants use improved v2 candidates.

See docs/design/EFFECT_DEMO_ASSETS.json for each file hash and each case's complete input/result binding. Keep attribution and actual pairing. Full execution prompts and private experiments stay server-side; no private photos are included. Do not interpret asset availability as generation, indexing, deployment or model-evaluation approval.
