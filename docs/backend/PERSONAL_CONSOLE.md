# 个人控制台实现

阶段2在现有日语账户/历史页面扩展，保持Web与Vercel API同仓库。组件在`components/personal-console.tsx`，账户入口`account-pages.tsx`，筛选在`history-page.tsx`；样式使用现有tokens和局部CSS Module，未复制其他工作树的未提交品牌/Auth改动。最新品牌/字体/Auth/SEO已通过隔离组合构建和桌面/320px实际交互复核，见[兼容记录](../integration/CONSOLE_UI_INTEGRATION.md)；实际Git合并仍单独执行。

## 用户可见功能

- `/ja/account`默认总览：当前余额/预留、进行中任务、待确认付款、最近30日本自然日任务与实际消耗、最近任务和仍有效作品；编辑/充值/订单入口复用。
- 作品标签：集中查看成功任务，按可用/已过期/已删除/缺失筛选，进入现有任务详情查看、下载、继续编辑及删除。没有延长图片保留期。
- 积分标签：原余额及充值入口＋稳定分页流水，按类型筛选。利用可能/预留的增减分开，关联本人任务/订单；不显示内部business_key。
- 历史页：状态、工具、日本起止日期筛选与分页；结束日包含当日，换算UTC半开区间。无结果与首次使用分别提示。
- 查询失败显示错误及重试，不生成假0；账户限制提示保留。账户组件按已验证登录用户ID重新挂载，取消旧请求，不复用前一人的统计与列表。
- 五标签支持左右/Home/End键与水平滚动；手机积分表可横向滚动并有提示，日期/状态表单可换行。

## 接口与数据

新增`202610210200_personal_console.sql`在阶段1迁移之后应用；本轮尚未应用云端。

| GET接口 | 返回 |
|---|---|
| /api/dashboard | 单条SQL读取快照：余额、30日本自然日任务、账本consume实际消耗、全时段进行中/待确认付款、最近各5条任务/可用作品 |
| /api/credits/ledger | 本人流水；kind/start/end筛选，最大50条 |
| /api/account/jobs | 本人任务；status/tool_id/start/end筛选，最大50条 |
| /api/account/works | 本人成功作品记录；availability/tool_id/start/end筛选，最大50条 |

精确Schema在contracts与生成OpenAPI。拒绝任意user_id/owner_id、重复参数、错误日期/区间、未来before与游标注入。工具筛选支持稳定字符串，不依赖图表正好20项。

分页使用完整微秒时间＋UUID降序游标。首屏返回snapshot_before，后续传入before并保持相同筛选，避免期间新建记录混入。as_of是**本页实际读取时间**，不是历史状态重建；状态、删除/到期按本次读取判定。没有为了跨请求固定游标而延长图片权限。旧/api/jobs不改协议，过滤页面改用新增个人端点。

统计消费只求kind=consume的-reserved_delta；预留/释放/购买不混计。任务计数按创建时间，正在进行总量跨全保留历史，避免遗漏30天以前尚未终态任务。所有数据RPC仅service_role执行，身份由API验证Bearer后绑定，不接受浏览器选择owner。
