# マイページ与サポート导航

2026-10-22，Web `feat/account-support-navigation`，基于生产 main `281742f`。本轮仅本地实现，尚未推送、合并或部署。

## 信息架构

| 入口 | 目标与行为 |
|---|---|
| 桌面主导航 | ツール、写真を編集、料金、サポート；移除全局履歴 |
| 手机底部导航 | ツール、編集、サポート、マイページ；未登录时末项显示ログイン |
| マイページ `/ja/account` | 顶部常驻编辑历史与支持快捷入口，所有账户标签及读取失败时均可找到；退出按钮保留 |
| 账户下拉菜单 | マイページ、編集履歴、サポート、ログアウト |
| 编辑历史 `/ja/history` | 既有受保护页面；新增返回マイページ链接，手机个人导航归属マイページ |
| 编辑页手机顶部 | 44px问号图标进入支持；保持编辑页单层底部操作栏 |
| 支持 `/ja/help` | 未登录可访问，页脚同步称サポート；沿用上传、编辑、积分/支付、保存问答，补登录/个人页/退出帮助 |

历史URL、登录后返回目标、AuthGate、用户身份key、取消旧请求及API数据隔离保持原实现。帮助页既有`#help-2`支付链接不变，账户帮助追加为`#help-4`。

## 支持范围

当前提供常见问题与排查说明。正式客服邮箱、工单及客服后台尚未配置；保留页面的“問い合わせ窓口は公開準備中”说明，不创建虚构邮箱或不可提交的联系表单。
