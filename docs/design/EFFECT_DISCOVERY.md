## 真实样例与公开边界

现有六风格实验采用同一儿童人像。原始文件保留在工作区 Worker 私有 artifacts，本轮只读取并压缩副本，未修改 Worker。7 张预览图约 343KB，去除元数据后放在 Web 的 `apps/web/.local/effect-samples/`，Git 忽略，不进入 public 或 Git。

开发服务仅监听 `127.0.0.1`。`NODE_ENV=development` 且完整样例集合存在时才展示本地样例；`/api/local-effect-samples/[asset]` 只允许本地主机与固定文件名，响应 private/no-store/noindex。生产构建不读取样例集合，图片路由返回404。Next.js tracing 显式排除 `.local`，postbuild 扫描部署清单和静态 HTML，若发现私有文件或本地样例 URL 则构建失败。

公开样例清单目前为空。将来需使用获准发布、完成效果审阅的独立公开素材，按固定版本补入清单；不能直接把本地照片移入 public。本地预览具备完整视觉交互，并不意味着这些人像已获准上线。

实验中的动漫、贴纸、3D、Q版为单图返回；毛毡与切纸来自多图异常响应中原先选取的第一张，页面另有说明，不包装为已验收的稳定功能。样例是实际实验结果，不是通过正式 Web 任务完成的效果证据。

## 接口与状态

风格参数不扩展现有 API 枚举。`anime`、`chibi` 可作为已有 `ai_avatar` 的 `parameters.style`，其他四种实验风格目前只供对比，不静默映射为近似风格。模板、模型与服务端完整 Prompt 保持独立，浏览器不读取实验 Prompt 或供应商响应。

新的明确风格选择会使旧的待重试请求失效；风格未改变时保留原幂等请求。草稿仍按 owner 隔离，账户切换只恢复对应账户的草稿，沿用原认证和退出逻辑。上传、积分、生成、历史任务和后端协议未被替换。

可用状态继续读取同源 `/api/tools`，当前生成关闭，页面明确显示准备中。编辑页、预览与实验样例不能视为已开启付费生成。
