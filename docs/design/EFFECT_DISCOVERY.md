# 效果展示与头像详情首轮优化

更新：2026-10-21。目标仓库为 picjp-web，分支 `feat/effect-discovery`，基于 main `0c49fae`。本轮仅本地实现与验收，没有推送、合并 main、Vercel 部署或新增模型调用。

## 用户可见变化

- `/ja`：用户后续选定概念图中的成年女生，现主视觉使用按该形象重建的独立AI生成原图，明确标注为源图而非编辑结果；下接四种既有试作风格卡片、工具分类、步骤和FAQ，说明试作卡片来自另一张原图。对比组件仍用于头像详情，待女生真实结果就绪后再配对。
- `/ja/tools`：图片式工具卡片，保留搜索、类别、18 个当前功能方向及 API 可用状态。仅头像有本地真实样例，其余显示「仕上がり例は準備中」，不把头像实验套用到其他工具。
- `/ja/tools/ai_avatar`：完整头像效果详情，支持六种风格切换、原图／结果／并排比较、选择状态、编辑入口、步骤、输入建议、限制、FAQ 和关联工具。继续使用服务端 SEO 正文、修订与索引门禁。
- `/ja/edit?tool=ai_avatar&style=anime` 或 `style=chibi`：选择可带入已有参数表单；登录 next 保留选择。切换详情风格也更新 example 查询参数，刷新和登录回跳可恢复该风格。

## 真实样例与公开边界

现有六风格实验采用同一儿童人像。原始文件保留在工作区 Worker 私有 artifacts，本轮只读取并压缩副本，未修改 Worker。7 张预览图约 343KB，去除元数据后放在 Web 的 `apps/web/.local/effect-samples/`，Git 忽略，不进入 public 或 Git。

开发服务仅监听 `127.0.0.1`。`NODE_ENV=development` 且完整样例集合存在时才展示本地样例；`/api/local-effect-samples/[asset]` 只允许本地主机与固定文件名，响应 private/no-store/noindex。生产构建不读取样例集合，图片路由返回404。Next.js tracing 显式排除 `.local`，postbuild 扫描部署清单和静态 HTML，若发现私有文件或本地样例 URL 则构建失败。

公开样例清单目前为空。将来需使用获准发布、完成效果审阅的独立公开素材，按固定版本补入清单；不能直接把本地照片移入 public。本地预览具备完整视觉交互，并不意味着这些人像已获准上线。

实验中的动漫、贴纸、3D、Q版为单图返回；毛毡与切纸来自多图异常响应中原先选取的第一张，页面另有说明，不包装为已验收的稳定功能。样例是实际实验结果，不是通过正式 Web 任务完成的效果证据。

## 接口与状态

风格参数不扩展现有 API 枚举。`anime`、`chibi` 可作为已有 `ai_avatar` 的 `parameters.style`，其他四种实验风格目前只供对比，不静默映射为近似风格。模板、模型与服务端完整 Prompt 保持独立，浏览器不读取实验 Prompt 或供应商响应。

新的明确风格选择会使旧的待重试请求失效；风格未改变时保留原幂等请求。草稿仍按 owner 隔离，账户切换只恢复对应账户的草稿，沿用原认证和退出逻辑。上传、积分、生成、历史任务和后端协议未被替换。

可用状态继续读取同源 `/api/tools`，当前生成关闭，页面明确显示准备中。编辑页、预览与实验样例不能视为已开启付费生成。

## 品牌与响应式

沿用云朵 Logo、A1 字标、Zen Kaku Gothic New 正文／按钮、Zen Maru Gothic 重点标题、白底／奶油表面／暖棕正文／珊瑚色操作。图片圆角12px，按钮与对比操作至少44px。手机风格选择为三列，首页风格与工具卡片为两列；不依赖 hover 或拖动，保留移动账户入口及底部导航。

概念参考保存在父工作区 `docs/design/concepts/effect-discovery-2026-10-21/`，只作设计参考，不作为模型结果或页面素材。已用 view_image 对照概念与实际截图，复核以下内容：

| 项目 | 实现与有意调整 |
|---|---|
| 布局 | 首页分栏对比、四张风格卡和后续目录；详情先看样例再进入编辑，手机纵向排列 |
| 文案 | 保留短日语标题、风格名称与编辑入口；删除概念图自行添加的效果保证、工具和虚构数据，沿用真实可用状态 |
| 字体 | 浏览器计算样式确认正文 Zen Kaku、标题 Zen Maru；修正窄屏标题断行 |
| 颜色与品牌 | 使用既有品牌变量、真实 Logo／A1 字标，不采用概念图近似字标或渐变按钮 |
| 图像与圆角 | 实际使用已有实验图、完整原图与说明；不使用概念图的虚构成人效果，按原比例 contain 展示，不裁掉对比信息 |
| 手机交互 | 点击切换、可见选中框、44px以上操作、原账户导航；320/390px无整页横溢 |

本轮以已批准的设计方向和现有品牌为基准完成实现；概念图中的人物、近似 Logo、额外功能和无依据宣传不作为实现规格。
