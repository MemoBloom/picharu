# 决策记录、假设与待办（持续维护）

## 已确定的产品方向
- 日本普通消费者优先，不做复杂专业设计工具。
- 类似 image25.top 的聚合模式，但前端按任务和效果组织，而非模型品牌。
- Image Edit 为初期重点；SEO 是长期获客手段，初期并行小额广告和创作者推广。
- Phase 1 只用商业图像编辑模型 API 的 1–2 个端点，单个中转服务优先；不自研模型、不建设复杂模型路由。
- 用户于 2026-10-19 确认：首期从完整 20 个工具开始需求与技术架构论证，原六工具方案失效；清单和稳定 ID 见 `docs/product/BASELINE_REQUIREMENTS.md`。分批开发或质量暂缓公开不缩减架构范围。
- 智能扩图曾在实际产品场景验证用户价值低，**不纳入首发核心功能**。
- 商用收费偏好：对偶发用户采用积分包；定价尚未决议。
- 品牌候选：Picmofu、Picraku、Picharu，均未确认可注册、未完成商标审查。

## 需要确认的外部事实
- 真实商业 API 模型 ID、功能、成本、调用限制、中转商资质和再提供权。
- 日本市场的关键词搜索量、难度、CPC、竞争格局、社区和广告获客成本。
- 支付、税务、消费者权益、隐私法规与跨境处理义务，由合规人员核验。
- 域名状态和日文/英文商标冲突。

## 目前开放的问题
- 选择哪家中转服务？是否支持真正编辑、多参考图、结果删除？
- 20 个工具各自的输入/输出规格、多图和保真要求、免费额度及成本到日元售价如何确定？
- 首发是否要求注册，匿名滥用如何处理？
- 需要保留用户历史图片多久？是否提供立即删除？
- A/B 试验：实用工具还是趣味工具付费更好？
