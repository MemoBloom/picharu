> 研究基线：2026-10-15。项目定位：日本普通消费者、无需 Prompt 的 AI 图片编辑聚合站。

## 产品边界

- 用户路径：搜索/社交入口 → 查看真实样例 → 上传 → 选择效果/涂抹 → 结果预览 → 下载/分享。
- 当前首期设计范围：统一清单的完整 20 工具；原六工具及透明背景/高清化等历史优先级已失效。Tool ID 以 `docs/product/BASELINE_REQUIREMENTS.md` 为准。
- 不承诺精确身份保持、虚构细节的真实性、准确虚拟试衣、生成式重绘后的商品真实性。
- 付费建议：透明的 Credits、显示每次费用、失败退积分、少量免费体验及成本封顶。
- 安全/隐私：处理肖像需授权；明确删除时限；私图禁止默认公开；不得移除不属于自己的版权/认证标识以误导他人。

## 底层链路

- **R1**：通用指令图像编辑
- **R2**：分割/蒙版 + 修补
- **R3**：主体分割与透明度处理
- **R4**：图像恢复/增强专用模型
- **R5**：多参考图合成或任务专用模型
- **R6**：OCR + 修补 + 排版
- **R7**：确定性图像计算
