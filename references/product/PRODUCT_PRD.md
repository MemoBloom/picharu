# 日本面向普通用户的 AI 图片编辑聚合站 — 产品需求文档（PRD）

> 版本：0.4 / 2026-10-19。状态：讨论方案，不代表已完成用户研究。第一阶段以 `docs/product/BASELINE_REQUIREMENTS.md` 的 20 工具范围为约束，结合更新后的 `references/product/PHASE1_COMMERCIAL_API_MVP.md` 论证交付方案。

## 1. 产品定位与非目标
- **产品**：面向日本普通消费者的轻量化 Web AI Image Edit 工具聚合站。用户不需要了解模型、不需要学习画布编辑、不需要编写复杂 Prompt；上传一张照片，挑选效果，生成并下载。
- **目标人群**：希望修饰日常照片、制作 SNS / LINE 头像、转换插画风格、处理旅行和宠物照片的日本普通用户。不是设计师优先、企业级协作或专业创意工作台。
- **价值主张**：功能直接可用、日语自然、移动端友好、收费透明、能用少量积分完成任务。
- **价格理念**：和综合设计软件的年订阅区分，以低门槛按需付费为主，辅以轻会员。任何价格均待成本核算和 A/B 测试。
- **明确非目标**：复刻 Canva 编辑器；以模型数量为卖点；第一阶段自研模型；复杂编排、多供应商自动选路；智能扩图作为首发核心功能。

## 3. MVP 范围
- P0：完整 20 个工具的需求、配置与页面设计，共享上传-配置-生成-结果流程并支持工具间输入/参数差异；多图、身份/结构保持、版本、计费、恢复和埋点必须逐项论证。有限免费体验、日语 FAQ 与隐私说明纳入统一设计。分批灰度不改变范围。
- P1：在 20 工具基线上完善经过评测的样式模板与体验，不把已有 20 项中的工具重新归为“以后再设计”。**智能扩图仅保留于候选池，非首发推荐功能**（先前已验证用户价值较低）。
- P2：对被验证具有需求且商用模型难满足的能力接入专项 API、CV 服务或自研模型。
- 参考历史 56 项研究及新增调色项组成的 57 项候选池：`references/product/IMAGE_EDIT_FEATURE_CATALOG.md` 和 CSV。原文件里的历史优先级不覆盖此 PRD。

## 4. 用户体验关键原则
1. 首页入口按效果或问题分组：写真をきれいに / 写真で遊ぶ / ペット・思い出，而非模型型号。
2. 工具页首屏展示真实前后效果和一次明确操作（上传图片）。
3. 生成入口不得强制用户学习 Prompt；可通过模板卡和简短自由描述扩展。
4. 移动优先；上传、状态、失败、重试、结果对比、下载都必须顺畅。
5. 处理前准确展示消耗积分、是否可能改变主体细节和输入照片保留策略。
6. 失败不应无故扣除用户积分，退款或返还逻辑与支付规则一致。
7. 对人像、商品真实性和旧照片修复避免作出绝对保真承诺。

## 5. 核心业务规则（待定参数）
- 账号：可先匿名预览，真正生成/下载的免费额度需要防滥用；可选择邮件或第三方登录，具体以实现成本确认。
- 消费：按任务预估积分；调用成功且结果可交付后扣费。对超时/失败/重复请求作幂等处理。
- 支付：日元展示一次性积分包与可选订阅；列出退款、续费、取消规则，明确是否含税。
- 数据：临时图片设定明确清理期限，用户可删除历史；具体期限待隐私/供应商审核。
- 内容合规：用户上传需取得授权；对非自愿私密、侵犯他人肖像、欺诈或侵权用途设安全限制。

## 6. 核心指标
- 首次生成完成率 = 成功完成首个生成的有效上传用户 / 发起首个生成的有效上传用户。
- 有效任务成功率 = 人工或真实用户判定可用输出 / 所有正常完成输出。
- 单次成功结果成本 = 总 API、存储、重试成本 / 可接受的成功结果数。
- 下载率、二次使用率、分享率、访问→生成率、激活→付费率、30日复购率。
- 按工具页与渠道独立统计，不将广告流量混入 SEO 自然搜索表现。

## 7. 风险与验证
- 商用 API 真实效果、模型版本、可转售权：采购与法务验证。
- 图片上传隐私和删除：完成技术、隐私和供应商条款审查。
- 日本日语搜索量、CPC 和用户支付意愿：尚无经核实数据，必须实测。
- 降价不是可持续壁垒；关键是效果完成率、单位成本、低学习成本与低价按次消费。
