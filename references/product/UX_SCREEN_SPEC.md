# 用户旅程与页面/交互规范

> 2026-10-20：当前开发前提案见 [前端页面、功能入口与跳转设计](../../docs/product/FRONTEND_PAGE_MAP.md)，明确 14 类页面、12 个模板及共享工作台。本文件保留导入时的体验背景；页面职责差异按新提案评审，不能据此认定页面或 Worker 已实现。

## 1. 导航结构
- `/ja/` 首页：工具搜索/分类/热门实测效果、最近使用、价格与信任信息。
- `/ja/tools/[slug]`：覆盖统一清单的 20 个工具，按四类导航；Tool ID 与 slug 映射统一管理。原有去路人、去杂物、换背景、插画、宠物和头像 URL 仅为部分例子，不代表完整范围。
- 首页推荐和自由编辑按技术包方案设计；多图合成需配置多图上传、次序/角色、逐图校验和失败恢复；结果支持继续编辑与版本关联。
- `/ja/pricing` 价格、积分说明、使用条款、退款与取消订阅。
- `/ja/help` 使用说明、隐私说明；`/ja/blog/` 具体场景教程。

## 2. 标准工具页 UI
1. Hero：日语任务型 H1、一句话价值、明确上传按钮、真实 before/after。
2. 上传：按工具声明提供单图或多图；拖拽/文件选择/手机照片库；明确格式、尺寸、隐私。检查 EXIF 方向，不默认公开原图。
3. 参数：2–6 个可以预览的风格卡或可选提示；去人去物首版使用简短自然语言指定对象，不宣传精确画笔擦除。
4. 生成：展示积分消耗、处理状态、取消/超时处理、失败重试提示；异步任务允许页面状态恢复。
5. 结果：原图/输出对比、再次生成、下载、反馈；分享为用户主动选择，不强制水印传播。
6. 支持：FAQ、相关工具、价格、个人照片如何处理。

## 3. 日语页面示范
- 标题：`写真から人を消す｜AIで不要な人物をかんたんに削除`
- 说明：`旅行写真に写り込んだ人を、写真をアップロードしてかんたんに編集。`
- 主按钮：`写真をアップロード`；执行：`AIで編集する`；下载：`画像を保存`。
- 不应承诺：`100%自然`、`完全無料`（除非确实无限免费）、`本人確認書類に使用可能`。

## 4. 移动体验验收
- 全部 20 工具纳入流程验收，覆盖多图、局部改色与严格保真场景；先开发部分工具不能代替完整设计。
- 360px 及更小视口无水平溢出；首屏清楚展示唯一主 CTA。
- 上传取消、网络中断、失败、超出额度均有恢复路径。
- 关键流程无模型名选择要求；文字可随日语长度自然换行。
- 图片示例必须为真实 API 输出或注明示意。
