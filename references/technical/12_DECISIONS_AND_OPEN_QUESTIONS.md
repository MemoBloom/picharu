# 已定决策与待验证事项

> 文档基线：2026-10-19。面向日本普通消费者；香港公司经营；首期使用商用图像 API；以下“目标”不是已通过实测的指标。

## 已定决策 (DECIDED)

- 日本普通消费者、低价按需的 AI 图片编辑聚合站，非 Canva 式综合画布。
- 用户于 2026-10-19 确认完整 20 个工具为首期需求及技术架构论证基线；六工具方案已被替代。分批执行不缩减设计范围。用户进一步明确 20 效果仅为初期，首版无需一次完善，重点是适配后续模型能力迭代；模板初期按 20–50 个规划，不设长期硬上限。智能扩图不再首发。
- 首期 GPT Image / Nano Banana 一类商用 API，选择 1–2 个有效端点；不自研模型。
- 用户自选工具与 JEV 智能推荐并行存在；另有自由 Prompt 和连续编辑。
- Prompt JSON 位于 GitHub；Vercel 读取全部已启用模板的**丰富推荐资料**传给 JEV；JEV 回传 Top-K ID；Vercel 组装完整 Prompt 并保存生成快照；Worker 无需同步模板库。
- Vercel 东京承担前端+轻量业务 API；Supabase 东京承担 Auth/PG；美国已有 Lambda GPU 部署 JEV；Cloud Run 东京执行长任务；R2 私有对象存储；Stripe Hong Kong 负责支付。
- Agent 并行且必须冻结接口契约；图像与资金流有统一 ID、状态与幂等。
